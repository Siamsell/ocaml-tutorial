##  Installation et utilisation

### Accès en ligne (recommandé)

Le site est accessible directement depuis votre navigateur :

**[https://siamsell.github.io/ocaml-tutorial/](https://siamsell.github.io/ocaml-tutorial/)**

Aucune installation n'est nécessaire pour consulter les cours.

### Développement en local

Pour récupérer le projet et l'exécuter sur votre ordinateur :

```bash
# 1. Cloner le dépôt
git clone https://github.com/siamsell/ocaml-tutorial.git

# 2. Accéder au répertoire du projet
cd ocaml-tutorial

# 3. Démarrer un serveur local avec Python
python3 -m http.server 8000

# 4. Ouvrir le site dans votre navigateur
# http://localhost:8000
```

### Installer OCaml

Pour exécuter les exercices OCaml sur votre machine :

**Ubuntu / Debian**
```bash
sudo apt update
sudo apt install ocaml opam
```

**macOS**
```bash
brew install ocaml opam
```

**Windows (via WSL)**

```bash
wsl --install
```

Après l'installation de WSL, ouvrez votre terminal Linux et exécutez :

```bash
sudo apt update
sudo apt install ocaml opam
```
